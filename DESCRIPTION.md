# Repository description

Industry-facing benchmark suite for core-conditioned PDQ factorization in reduced-order modelling, digital-twin compression, and sparse-sensor reconstruction.

The repository validates PDQ on structural, thermal, and power-grid style response systems using strong baselines, ablations, physical error metrics, storage/runtime evidence, and reproducible CSV/figure outputs.

## Short GitHub About description

Core-conditioned PDQ benchmarks for industrial reduced-order models, digital twins, and sparse-sensor reconstruction.

## Longer description

This repository provides a clean, testable validation suite for PDQ surrogate factorization. It compares PDQ ridge, conditioned-core PDQ, SVD/POD, randomized SVD, mean-response baselines, and ablations across industry-style structural, thermal, and grid systems, reporting reconstruction error, energy/operator residuals, runtime, storage ratio, sensor reduction, and core conditioning.
